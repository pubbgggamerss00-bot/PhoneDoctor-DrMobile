# پزشک گوشی (Phone Doctor / DrMobile) — نسخه ویرایش‌شده

این پروژه شامل **نسخه ویرایش‌شدهٔ** اپلیکیشن «پزشک گوشی» (پکیج `com.abbas.drmobile`) است که با ابزار `apktool` دیکامپایل، ویرایش و دوباره بسته‌بندی شده است.

## تغییرات اعمال‌شده نسبت به نسخه اصلی (1.0)

در تب «اطلاعات و درباره ما» (صفحه تنظیمات) این بخش‌ها **حذف** شده‌اند:

- ❌ بخش **شبکه‌های اجتماعی و کانال‌ها** (کانال تلگرام، یوتیوب و آپارات)
- ❌ بخش **درباره ما و کپی‌رایت** (کارت «درباره برنامه و صاحب اثر» + متن سلب مسئولیت و کپی‌رایت)

برای هماهنگی، عنوان صفحه به «اطلاعات و امکانات» و زیرعنوان آن به «امکانات، امتیازدهی و سایر برنامه‌ها» تغییر کرده است.

تمام بخش‌های دیگر برنامه (تست‌های سخت‌افزاری، ابزارها، ارتقای Pro، امتیازدهی مایکت، سایر برنامه‌های سازنده) بدون تغییر و بایت‌به‌بایت با نسخه اصلی حفظ شده‌اند — فقط `classes2.dex` ویرایش شده است.

## ساختار مخزن

| مسیر | توضیح |
| --- | --- |
| `apk/PhoneDoctor-1.0-patched-signed.apk` | فایل نهایی ویرایش‌شده، zipalign و امضاشده (v2+v3) |
| `project-source.zip` | پروژه کامل دیکامپایل‌شده apktool (سمالی + ریسورس‌ها + مانیفست) |
| `scripts/patch_smali.py` | اسکریپت اعمال پچ حذف بخش‌ها روی `SettingsAndAboutScreenKt.smali` |
| `scripts/swap_dex.py` | اسکریپت جایگزینی `classes2.dex` داخل APK اصلی با حفظ فشرده‌سازی بقیه فایل‌ها |

## محل تغییرات در کد

فایل: `smali_classes2/com/example/ui/screens/SettingsAndAboutScreenKt.smali`

- متد `SettingsAndAboutScreen$lambda$30$lambda$29$lambda$28` (بیلدر LazyColumn): از ۹ آیتم، ۶ آیتم حذف شد (سرتیتر و کارت‌های شبکه‌های اجتماعی + سرتیتر و کارت درباره ما/کپی‌رایت). ۳ آیتم باقی‌مانده: سرتیتر «امکانات مایکت و امتیازدهی»، کارت «ثبت نظر و امتیاز»، کارت «سایر برنامه‌های ما در مایکت».
- رشته‌های عنوان صفحه (`اطلاعات و درباره ما` / `امکانات، شبکه‌های اجتماعی و کپی‌رایت`) به مقادیر جدید اصلاح شدند.

## نحوه ساخت (Build) از سورس

```bash
# 1) استخراج project-source.zip
unzip project-source.zip

# 2) بیلد با apktool
java -jar apktool.jar b decoded -o rebuilt.apk

# 3) جایگزینی classes2.dex داخل APK اصلی (توصیه‌شده برای حفظ ریسورس‌های اصلی)
python3 scripts/swap_dex.py   # مسیرها را طبق نیاز خودتان ویرایش کنید

# 4) تراز کردن
zipalign -p -f 4 patched_unaligned.apk patched_aligned.apk

# 5) امضا
apksigner sign --ks keystore.jks --out signed.apk patched_aligned.apk
apksigner verify --verbose signed.apk
```

## نکات نصب

- حداقل اندروید پشتیبانی‌شده: API 24 (اندروید 7.0)
- چون امضای فایل با نسخه اصلی فرق دارد، ابتدا نسخه قبلی را حذف (uninstall) کنید.
- `minSdkVersion=24` است، پس امضای v2/v3 کافی و معتبر است.
